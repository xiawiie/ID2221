## 已做决策
| 决策 | 理由 |
| --- | --- |
| 当前目录作为项目根目录 | 用户明确指定后续在此实现和操作 |
| 两个现有数据目录均不移动、不删除 | 用户明确要求保留项目副本和同级镜像 |

| `Week1/datasets` 是项目运行数据目录 | 代码与项目文档必须使用项目内相对路径 |

## 错误记录
| 错误 | 尝试次数 | 处理 |
| --- | ---: | --- |
| `findings.md` 写入时混入校对备注 | 1 | 读取文件后用精确补丁替换为已验证统计 |
| 大型文档补丁在提交前出现脚本语法错误 | 1 | 工具拒绝执行且文件未改；后续拆成小补丁 |
| 首次打开实现文档时参数格式错误 | 1 | 移除无效参数后重新请求成功 |
| `.gitignore` 首次检查的 PowerShell 管道语法错误 | 1 | 改为先收集结果再输出 |
| 在非 Git 仓库中运行 `git check-ignore --no-index` | 1 | 确认命令要求仓库；改做静态规则检查，行为验证留到 Git 初始化后 |
| 误用 Bash here-string 语法重试 Git 检查 | 1 | 停止跨 shell 写法，改用原生 PowerShell 命令 |
| pip 下载 PySpark 停留在 0 字节 | 1 | 中止会话，改用 PyPI 固定 URL 下载并校验哈希后本地安装 |
| 三次工具调用输入或补丁文本无效 | 3 | 调用均在执行前失败或仅影响 findings；读取精确上下文后修正 |
